# EUR/USD Floating Overlay

تطبيق Android صغير يعرض سعر EUR/USD في شريط عائم فوق كل التطبيقات.

## مصدر السعر
- الصفحة التي طلبها المستخدم: https://sa.investing.com/currencies/eur-usd
- التطبيق يحمّل الصفحة نفسها داخل WebView مخفي، ثم يقرأ قيمة السعر الحية من DOM.
- يوجد fallback HTTP لنفس الرابط إذا تأخر WebView.
- لا يقرّب السعر إلى خانتين؛ يعرض النص كما يظهر في صفحة Investing.com (عادة 4 منازل لزوج EUR/USD).

## السلوك
- Overlay قابل للسحب.
- أخضر عند ارتفاع السعر، أحمر عند انخفاضه.
- Foreground Service مع START_STICKY.
- يحاول التشغيل بعد إعادة تشغيل الهاتف إذا كان مفعلاً.
- على Samsung: اجعل البطارية للتطبيق "غير مقيّد" للحصول على أفضل استمرارية.

## البناء
افتح المشروع في Android Studio (JDK 17) ثم:
Build > Build APK(s)

الحد الأدنى Android 8.0 (API 26)، target/compile API 35.

## ملاحظة مهمة
Investing.com قد يغيّر بنية الصفحة أو آليات الحماية في أي وقت. لأن التطبيق يعتمد على الصفحة نفسها وليس API رسمي، قد يحتاج selector إلى تحديث مستقبلًا. استخدمه للاطلاع وليس كمصدر تنفيذ تداول تلقائي.
